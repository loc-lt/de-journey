# Project 03 - Python in Data (1)

# **🏁 1. Objective**

You are required to use **Python + Faker** to generate synthetic data for an **E-commerce OLTP system**, and then load the data into your chosen SQL database:

- **PostgreSQL**
- **MySQL**
- **SQL Server**

Your dataset must follow the schema and business logic described below.

Each table’s data must be **relationally consistent** — all foreign keys must be valid and logically connected.

## **2. Project Workflow**

1. Define the **schema**.
2. **Generate data** for each table using Python `Faker`.
3. **Convert data types** as needed to match the schema.
4. **Insert the generated data** into your database.

## **3. Database Schema**

Below is the relational schema for your E-commerce dataset.

### **🏷️ 3.1 brand**

| Column | Type | Constraint | Description | Example | Faker Hint |
| --- | --- | --- | --- | --- | --- |
| `brand_id` | SERIAL | PRIMARY KEY | Unique ID for each brand | 1 | — |
| `brand_name` | VARCHAR(100) | UNIQUE | Brand name | "Samsung", "Adidas" | `faker.company()` |
| `country` | VARCHAR(50) | — | Brand's country of origin | "Vietnam", "USA" | `faker.country()` |
| `created_at` | TIMESTAMP | — | When the brand was created | 2024-11-10 08:30:15 | `faker.date_time_between(start_date='2024-01-01', end_date='2024-12-31')` |

**Logic:**

Each product is linked to exactly one brand.

### **📦 3.5 product**

| Column | Type | Constraint | Description | Example | Faker Hint |
| --- | --- | --- | --- | --- | --- |
| `product_id` | SERIAL | PRIMARY KEY | Product ID | 20001 | — |
| `product_name` | VARCHAR(200) | — | Product name | "iPhone 15 Pro 256GB" | `faker.catch_phrase()` |
| `category_id` | INT | FK → category(category_id) | Product category | 10 | random FK |
| `brand_id` | INT | FK → brand(brand_id) | Product brand | 3 | random FK |
| `seller_id` | INT | FK → seller(seller_id) | Linked seller | 501 | random FK |
| `price` | DECIMAL(12,2) | CHECK (price > 0) | Original price | 25000000 | `random.uniform(100000,50000000)` |
| `stock_qty` | INT | CHECK (stock_qty >= 0) | Quantity in stock | 120 | `random.randint(0,500)` |
| `rating` | DECIMAL(2,1) | CHECK (rating >= 0 AND rating <= 5) | Average rating (0–5) | 4.6 | `round(random.uniform(3,5),1)` |
| `created_at` | TIMESTAMP | — | When product was added | 2024-12-10 09:15:42 | `faker.date_time_between(start_date='2024-06-01', end_date='2024-12-31')` |
| `is_active` | BOOLEAN | DEFAULT TRUE | Product availability | TRUE | random True/False |

**Logic:**

Each product belongs to one category, brand, and seller.

`stock_qty` decreases when orders are created.

> **Note:** Discounted pricing is handled through the `promotion` + `promotion_product` tables, not stored directly on the product.

### **🧾 3.6 order**

| Column | Type | Constraint | Description | Example |
| --- | --- | --- | --- | --- |
| `order_id` | SERIAL | PRIMARY KEY | Unique order ID | 9001 |
| `customer_id` | INT | FK → customer(customer_id) | Customer who placed the order | 5001 |
| `order_date` | TIMESTAMP | — | When order was placed | 2025-03-15 10:45:00 |
| `status` | VARCHAR(20) | CHECK (status IN ('PLACED','PAID','SHIPPED','DELIVERED','CANCELLED','RETURNED')) | Order status | "PLACED" |
| `total_amount` | DECIMAL(12,2) | CHECK (total_amount >= 0) | Total order value | 1,250,000 |
| `created_at` | TIMESTAMP | CHECK (created_at >= order_date) | Record creation | 2025-03-15 10:45:00 |

**Logic:**

Each order is linked to a **customer** and contains multiple items. Seller information is derived from `order_item` → `product` → `seller`.

### **🎁 3.8 promotion**

| Column | Type | Constraint | Description | Example | Faker Hint |
| --- | --- | --- | --- | --- | --- |
| `promotion_id` | SERIAL | PRIMARY KEY | Promotion ID | 101 | — |
| `promotion_name` | VARCHAR(100) | — | Campaign name | "9.9 Mega Sale" | static/random words. input |
| `promotion_type` | VARCHAR(50) | — | Type of promotion | 'product', 'category', 'seller', 'flash_sale' | static choice |
| `discount_type` | VARCHAR(20) | CHECK (discount_type IN ('percentage', 'fixed_amount')) | Type of discount | 'percentage', 'fixed_amount' | static choice |
| `discount_value` | NUMERIC(10,2) | CHECK (discount_value > 0 AND (discount_type = 'fixed_amount' OR discount_value <= 100)) | Discount value | 10.00 (=> 10%) or 50000 (=> 50k) | — |
| `start_date` | DATE | CHECK (start_date >= DATE(created_at)) | Campaign start date | 2025-02-01 | `faker.date_between(start_date='2025-01-01', end_date='2025-04-30')` |
| `end_date` | DATE | CHECK (end_date >= start_date) | Campaign end date | 2025-03-02 | `start_date + timedelta(days=random.randint(30,50))` |
| `created_at` | TIMESTAMP | — | Record creation | 2025-01-15 09:00:00 | `faker.date_time_between(start_date='2024-12-01', end_date='2025-01-31')` |

**Logic:**

Defines promotional campaigns applied to products.
